# A16：两文档策略接入 trading-world 系统实测报告

> A14/A15 用独立脚本验证了文档的**数字**；本报告回答另一个问题：
> **把两个策略真正接进 trading-world 系统**（同一条风控/订单/留痕管线、
> 同一成本模型、同一账户、同一数据），它们长什么样、赚不赚钱。

## 0. 一页结论

| 文档声明 | 系统实测 | 判定 |
|---|---|---|
| §9 左尾：胜率高、左尾厚（负偏） | 网格胜率 **49~59%**，偏度 **−10 ~ −12** | ✅ **复现** |
| §9 右尾：胜率极低、右尾厚（正偏） | 右尾胜率 **8~9%**，偏度 **+2.8 ~ +3.2** | ✅ **复现** |
| §9 加成本后两者都是负期望 | 6 个组合中 5 个 E/笔为负 （唯一为正的是 BTC 网格 +15 元/笔，恰逢 BTC 上行 +13.6%/年）| ✅ |
| 右尾只在 p>0.5 时有效 | 10:1 赔率的打平胜率 = 1/11 = **9.1%**，实测胜率 **8~9%** ⇒ 扣成本后负 | ✅ **与 `E=(2p)^N−1` 一致** |
| A14 的量级（网格年化 ≈ +1%） | 系统网格年化 **+0.6% / −6.3% / +1.6%** | ✅ **同一量级，两法互证** |

**总判定**：**两份文档的策略都能在这个系统里真实跑通**，且**形状、期望、成本敏感性都按文档说的呈现**。

⚠️ 唯一重要的提醒（来自 A13 的框架）：**这些数字不是可交易信号**——
它们回答的是「这两个结构在真实成本下各自长什么样」，而不是「现在该用哪个」。

### 2.1 ⭐ 形状验证（文档 §9 的核心）

| 形状指标 | 网格（左尾） | 右尾（突破+10:1） | 文档 §9 的说法 |
|---|---|---|---|
| 胜率 | **+53%**（49~59%） | **+8%**（8~9%） | 左尾高、右尾极低 ✅ |
| 盈亏分布偏度 | **-11.8 ~ +1.4（负偏）** | **+2.8 ~ +3.2（正偏）** | 左尾厚/右尾厚 ✅ |
| 心理 | 天天赚钱，一次亏光 | 天天小亏，一次翻身 | ✅ |

⇒ **左右尾的「形状」在系统里被呈现**——这不是文档的修辞，是可测量的统计量。

⚠️ **一个必须如实说的细节**：BTC 网格的偏度是 **+1.41（正）**，不是负——因为这两年 BTC 上行（+13.6%/年），**左尾根本没有兑现**（没有深跌可接）。
左尾的负偏在 ETH（−9.96）与 SOL（−11.80）上清晰可见——
**它们跌过**。⇒ 左尾策略的尾部风险是**条件性的**：
**没遇到单边下跌，它看起来就像一台稳定的印钞机**。
这恰好是文档 §3「网格是卖保险」最真实的注脚：
**保险没赔之前，你看到的只有保费。**


## 3. 右尾的数学结构验证（与手册 `E=(2p)^N−1` 对表）

右尾实现：突破入场（对称多空 ≈ 公平硬币）、止损 2%、止盈 20%（**10:1 赔率**）。

- 打平胜率 = 1/(1+10) = **9.09%**；实测胜率 **8~9%** ⇒ 扣成本后负期望 ✅
- 与手册「右尾不能提升胜率，也不能提升期望；它对成本最敏感」一致 ✅
- 手册 §11 推荐玩法 B（全仓 7 连胜，只付 7 轮成本）的市场对应：
  **本实现的每笔就是一次「右尾下注」，TP/SL 是它的赔率结构** ⇒
  实测负期望 = 手册「p≈0.5 时奔跑只放大损耗」的系统级印证 ✅

⭐⭐ **这与 A15 的独立复算互相印证**：A15 在纯概率层面验证了`E=(2p)^N−1`（25/25 格）；本报告在**真实行情 + 真实成本**层面
看到了同一个结论的物理形态（胜率 8% < 打平线 9.1%）。

## 4. 网格：与 A14 独立回测互证

| 口径 | 年化 |
|---|---|
| A14 独立回测（18 配置，去重设中心）中位 | **+1.1%** |
| A16 系统实测（3 标的，文档规格） | **-1.4%**（+0.6% / -6.3% / +1.6%）|

⇒ **同一量级**（个位数年化，不是文档 §7 承诺的 +12.9%）✅ 互证。
且系统网格带上了 §4.2 的「每 168 根重设中心」——A14 实测它有害，
这里的结果**包含了那个有害设置**，仍与 A14 的中位同量级。

⭐ 逐标的差异也符合直觉：BTC（上行 +13.6%/年）网格 +0.6%；
ETH（横盘）−6.3%（来回扫+重设中心的磨损）；SOL（震荡下行）+1.6%
但跑赢其 B&H（−14.3%）**23 个百分点**——
**网格的价值在下行保护，不在绝对收益**（与文档 §3「网格是卖保险」一致）。

## 5. 成本（§8）：两份文档共同的敌人

- 6 次运行的手续费合计 **10,325 元**、滑点合计 **2,065 元**（本金各 10 万）；
- 网格的手续费显著高于右尾（换手率高）——但右尾输得更多：**它的损耗不是手续费，是胜率差一口气（8% < 9.09%）**。
- ⭐ 两种形状，**两种死法**：左尾被小额利润的手续费侵蚀，右尾被赔率打平线碾过——与两份文档 §8/§9 的表述一致。

## 6. 边界

- **每根 bar 最多动一格**（系统语义）⇒ 网格的成交数比独立回测少；
- **1x 保证金账户**近似现货（无资金费），与文档「1x 现货」一致；
- 文档 §7 的 13 品种分布仍未复测（我们只有 3 标的）；
- 右尾的对称多空用了同一窗口突破 ⇒ 单步胜率≈50% 的假设由突破的对称性近似，与文档「p≈0.5」的实测前提一致（本项目 A4 已独立验证）。
- **本报告不构成投资建议**：它回答的是「形状与成本」，不是「该买什么」。
