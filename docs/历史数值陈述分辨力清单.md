这是全项目**被引用次数最多**的一个数字（二期阶段6/8、三线 A 线都以它为出发点），所以单独审计：

- 原始 k（未饱和 3 档）= **1.248**（γ = 0.801），95% CI = **[0.491, 3.116]**（宽 2.625）

- 但同一份数据，只要把档位从 3 档扩到 4 档（接纳 1 个饱和档），CI 下界就从 0.491 抬到 ~0.71 ——**方向性判断在扩档位后站得住**（详见工作线J 小结）
- 判定：**已审计**（不重复劳动），结论见 `docs/分辨力危机-交付小结.md`

### 3.3 确认不适用本条纪律（不是遗漏）

| 类别 | 例子 | 为什么不需要 CI |
|---|---|---|
| 直接可观测量 | 稀疏化生效占比 99.2%、净/总暴露 0.226 | 数出来的占比，不经拟合 |
| 确定性比值 | λ̄ 标尺偏差 1.767×、0.935× | 两个实测值相除，不是统计估计 |
| 逐位一致 | 复现自查差 0.000 | 同种子确定性复现 |
| 事件率 | EA.0 的公式偏差 <1% | 直接测的到达率 |

## 4. 结尾：这份清单要来干什么

**不是要求本轮把所有裸奔陈述都补上 CI**——那是开放式的长期工作。
它要解决的是：**以后回头看历史结论时，能一眼看出哪些可信、哪些需要重新核实。**

配合新增的第七条纪律（「先报 CI 再报差」），从此：

1. **新写的**陈述必须带 CI / 标准误 / 种子数，否则只能算「当次读数」；
2. **旧的**陈述按本清单分级——k 类一律降级为「当次读数」；
3. 再出现「A 变到 B」式的比较时，先问一句：**这个指标的区间有多宽？**
