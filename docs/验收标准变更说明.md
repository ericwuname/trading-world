# 验收标准变更说明：从「k 精确接近 0.5」到「方向性偏离检验」

> 提出于「一致性审计与收尾」那一轮（工作线P）。
> 依据：`前置校验-EA4-诊断报告.md`、`分辨力危机-交付小结.md`、
> `回填标准配置与H4做实-交付小结.md`、`一致性审计-交付小结.md`。

## 1. 原来是什么标准，为什么要改

项目原先的目标可以概括成一句话：**让冲击律的指数 k 接近 0.5（平方根律）**。
二期为此投入了「长记忆订单流」这条技术路线，验收口径是「k 从 X 改善到 Y」。

**这条路线的测量基础在后续两轮里被逐步拆掉了：**

| 轮次 | 发现了什么 |
|---|---|
| 前置校验（EA.4 扶正） | k 这个刻度**没有分辨力**：同一装置算出的 **19/19 个臂**，95% 区间全都包含 0.5；宽度中位数 2.331。而所有讨论过的差异只有 0.3~0.9 ⇒ **这些比较全部分辨不了**。要判定「是否落在 0.5±0.1」约需 **300 个种子**（当时用 3 个）。 |
| 分辨力危机 | 试图换判据（局部弹性）**失败**——它比全局拟合**更**没分辨力（117/117 对判「不可判定」）。真正有效的是**扩观测点**：3 档 → 7 档，CI 宽度 2.662 → 1.193（−55%），**代价近零**。 |
| 回填标准配置 | 把 8 个历史家族用「8 种子 × 未饱和档」重跑后，**6 个家族的 CI 排除了 0.5**。⇒「是否**显著偏离**平方根律」这个**方向性**问题，在当前配置下**可以**给出确定答案。 |

**结论**：「精确逼近 0.5」在当前装置下做不到（需要几百到上千个种子）；
「是否显著偏离平方根律」做得到。所以标准从**数值目标**改成**方向性判据**。

## 2. 新标准

对任意一次冲击律拟合，报出 k 与它的 95% 区间，然后分三类：

| 标签 | 判据 | 含义 |
|---|---|---|
| `sqrt_law_excluded_偏线性(k>0.5)` | CI **排除 0.5**，且 k > 0.5 | **确认显著偏离平方根律**，方向是「比平方根律更陡」 |
| `sqrt_law_excluded_偏超凹(k<0.5)` | CI **排除 0.5**，且 k < 0.5 | **确认显著偏离平方根律**，方向是「比平方根律更凹」 |
| `sqrt_law_consistent` | CI 包含 0.5 但排除 1.0 | 不能排除接近平方根律 |
| `undetermined` | CI 同时包含 0.5 与 1.0 | **完全无法判断** |

实现：`tw/analyzer_consistency.py::direction_verdict`，
批量打标签：`scripts/tag_final_verdicts.py`。

**配套的装置性要求**（来自分辨力危机那一轮的量化结论）：

- 参与拟合的**未饱和档位 ≥ 4 档**（df ≥ 2 ⇒ t 临界值 4.30 而不是 12.71）；
- **最大档位的 |t| 明确显著**；
- 标定窗口必须等于实验窗口（第六条纪律）。

> 这三条是**装置要求**，不是结果要求——它们可以事先检查，
> 而不是等结果出来再争论「这次算不算数」。

## 4. 两类判定不能混（这一条是踩过坑才写下来的）

| | 单个家族的**方向判定** | 家族**之间**的比较 |
|---|---|---|
| 依赖什么 | 它自己的 CI 是否排除 0.5 | 两个 CI 的重叠比例 |
| 受一致性审计影响吗 | **不受** | **受影响** |
| 例子 | `EA4_taker` 是 `sqrt_law_excluded_偏线性` | 「+基本面派比基线差」已**撤回** |

「一致性审计」那一轮发现：报告里两条「历史结论被推翻」只凭**点估计方向变化**，
实际区间重叠是 **100%** 和 **80.9%** ⇒ 连方向变化都不该被当成结论。
所以：

> **第十条纪律**：任何「此前 A 更好 → 现在 B 更好」这类方向反转的陈述，
> 必须用区间重叠度量正式检验；点估计换了方向只能说「新的读数如此」。

## 5. 这次变更**没有**做什么

- 没有放宽标准去迁就结果：方向性判据是**更弱但可判定**的要求，
  它并没有说「偏离平方根律就是好」——**「该不该逼近 0.5」是个独立的设计问题**，
  本轮不做判断。
- 没有删除任何历史表述：旧口径下的读数与结论都保留在各自轮次的报告里，
  只追加「后续已更正」的批注（见工作线Q）。
