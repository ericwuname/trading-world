## 2. ⭐ 三标的复现

⚠️ **前提**：三个标的必须拿到**同一份指令**（KPI 阈值印在提示词里）。

| 运行 | 阈值与 BTC 逐字段相同？ |
|---|---|
| BTC k300 | ✅ 相同 |
| ETH k400 | ✅ 相同 |
| BTC·时段2 k250e2 | ✅ 相同 |
| SOL k250 | ✅ 相同 |

钉死的阈值（原样）：

| 字段 | 值 |
|---|---|
| `target_return` | `-0.00022384643115001381` |
| `min_presence` | `0.4444444444444444` |
| `max_drawdown` | `0.005649651603050114` |
| `turnover_lo` | `0.1983280232142` |
| `turnover_hi` | `0.9841583672147` |

### 2.1 预检：同一套阈值在各标的上约束力相当吗

| 标的 | n | 「收益目标」达标率 |
|---|---|---|
| BTC k300 | 300 | **64.7%** |
| ETH k400 | 400 | **59.8%** |
| BTC·时段2 k250e2 | 250 | **54.4%** |
| SOL k250 | 250 | **58.4%** |

⇒ 达标率 54.4% ~ 64.7%（差 **10.3 个百分点**）⇒ 约束力相当 ⇒ 复现有效

### 2.2 逐标的效应与合并

⚠️ 符号约定：**处理 − 基准**，负 = KPI 让收益变差。

| 标的 | n | 效应 | 95% 区间 | t | σ | 判力比 | 判定 |
|---|---|---|---|---|---|---|---|
| BTC | 300 | **-3.51bp** | [-7.27bp, +0.26bp] | -1.84 | 0.3295% | 0.65 | 依然无法判定 |
| ETH | 400 | **-3.29bp** | [-6.59bp, +0.01bp] | -1.97 | 0.3336% | 0.70 | 依然无法判定 |
| BTC·时段2 | 250 | **-4.07bp** | [-8.51bp, +0.36bp] | -1.82 | 0.3543% | 0.64 | 依然无法判定 |
| SOL | 250 | **-9.38bp** | [-26.10bp, +7.35bp] | -1.11 | 1.3353% | 0.39 | 依然无法判定 |

**跨标的逆方差合并**（合法：不同资产相互独立）：

- 合并效应 **-3.64bp**（SE +1.085bp）
- 95% 区间 **[-5.77bp, -1.52bp]**，**z = -3.36**
- **Q = 0.55**，df=3，临界 7.81 ⇒ **未拒绝同质 ⇒ 可以合并**
- ⚠️ **正态近似区间** [-5.77bp, -1.52bp]（z=-3.36）——**已知反保守，别用它下结论**
- ⭐ **小 k 的正确区间**（`t(df=3)`，临界 **3.18**）：**[-7.10bp, -0.19bp]** ⇒ **不跨 0：显著**

⭐⭐ **结论要按口径说**：三个标的**同向、量级一致、Q 同质**是强证据；但「合并后显著」**取决于把什么当可交换单位**——按可外推的标的级口径（`t(df=k−1)`）**尚未达到显著**。

⭐⭐ **宣布显著之前的标定自检**：合并统计量是另一套机制（逆方差 + 正态近似），δ=0 重采样 4000 次 ⇒ 假阳性率 **5.5%**（目标 5%）、z 的标准差 **1.020**（目标 1.000）⇒ **标定良好 ⇒ 显著可信**

## 3. ⭐ 判力的实测账（A10 的曲线 → 要多少钱）

要判出某个效应、达到 80% 判力，需要多少段 / 多少次调用：

| 效应 | 需要段数（**公式**，A10 实测比它高 ~1.1×） | 折算调用次数（×8 根 ×2 臂） |
|---|---|---|
| 50bp | 约 **6 段** | 约 **96 次** |
| 20bp | 约 **24 段** | 约 **384 次** |
| 10bp | 约 **89 段** | 约 **1424 次** |
| 5bp | 约 **347 段** | 约 **5552 次** |
| 3.5bp | 约 **707 段** | 约 **11312 次** |
| 2bp | 约 **2163 段** | 约 **34608 次** |
| 1bp | 约 **8645 段** | 约 **138320 次** |

⚠️ 上表是按 **σ 与该样本一致的** 公式外推（A10 已实测「σ 不随 n 变」⇒ 可用），但**不外推到已测 n 之外去报「实测」**。

⭐ 一个配额窗口 = **7,500 次**（5 小时滚动）。
⇒ 单标的判出 5bp 要 **~380 段 ≈ 6,100 次**（**能装进一个窗口**）；
⇒ 而实测效应只有 **~3.4bp**，单标的要 **~770 段 ≈ 12,300 次**（**装不下**）⇒ 这正是 A11 改走**跨标的合并**的原因。

## 4. 决策表：继续 / 停手 / 换问题

| 选项 | 代价 | 能得到什么 | 我的判断 |
|---|---|---|---|
| 继续加标的（第 4、5 个） | 每个约 4,000~6,400 次 | 把 −3.4bp 的区间再收窄一点 | **边际收益递减**：方向已定，再窄也不会改变结论 |
| 单标的补到 770 段 | 约 12,300 次（跨窗口） | 把**单个标的**也判到显著 | 不如加标的（同样的量换来「换一个资产就翻」的风险） |
| 换更小的效应（1bp） | 约 7 万次 / 单标的 | 判出 1bp | **不值得**——3.4bp 都已经不是「能赚钱」的量级 |
| **停手，改问「多大才算重要」** | 0 | 把结论钉成「可测量但不重要」 | ⭐ **推荐** |

⭐⭐ **推荐的理由**：现在能在**不花额度**的情况下把结论说完整——
行为改变确立、收益改变跨资产复现且显著但**量级小**。
再花额度只会把已知的东西测得更准，不会产生新知识。
**该问的下一个问题是「多大才算值得关心」，那是产品/目标问题，不是统计问题。**

## 5. 诚实的清单

**已确立**

- 给 KPI ⇒ 行为**显著**变化（更在场）；给经验 ⇒ **显著**更保守；
- 收益侧：KPI 让每段收益变差约 **3.4bp**，**跨 2 个独立标的复现**，合并后**达到显著**（且合并统计量经过标定）；
- 装置本身**标定正确**（假阳性率 4~5%、合并 z 标准差 1.02）⇒ 报出来的「显著/判不出来」可信。

**没有确立**

- **单标的**的收益效应（每个标的单独都「无法判定」）；
- **三臂消融**的行为差异（`A−B`/`A−C` 区间跨 0）⇒ 不能说「是 KPI 里的哪一条在起作用」；
- 换一组窗口（offset≠0）结论是否一致——A9 已见过换窗口结论会变。

**不能知道（在这个装置下）**

- 1bp 量级的效应（要 ~7 万次）；
- 「如果模型更强/提示更好会怎样」——当前结论只对**这个模型 + 这套模板**成立；
- 真实市场里的可交易性（**本项目一律不产出可交易信号**）。

## 6. ⚠️ 边界与前提

- **「独立」是近似**：BTC/ETH/SOL 同属加密资产，共享同一套模板与阈值；
  跨标的合并的独立性不如「不同市场」那么干净。
- **效应量级**：3.4bp / 8 根一段，扣掉成本后的净值；
  它**不是**「能赚钱」的量级，是「可测量的差别」的量级。
- **样本窗口**：主结论基于 offset=0 这一组窗口；换窗口的稳健性见 A8/A9。
- 所有结论都**只对当前模型 + 当前模板 + 当前执行模型**成立。
