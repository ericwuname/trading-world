## 这条轨迹本身的价值

这个项目最有教育意义的地方不在任何一个具体的 k 值，
而在于它**反复把自己刚写下的结论拿回来重审**：

```
「意外修复」的乐观发现
   → 标尺假象（前置校验发现 k 换了标定口径会变）
   → 分辨力不足（19/19 个臂的区间都含 0.5）
   → 换判据失败（局部弹性比全局拟合更没分辨力）★ 自己推荐的路被自己证伪
   → 找到真正的解法（扩档位，代价近零）
   → 回填后发现历史结论方向变了
   → 再审一次：那两条「方向变了」其实也是噪声 ★ 再审自己刚写的「推翻」
```

第十条纪律（反转类陈述必须走区间重叠检验）就是这条轨迹的直接产物。
