4. 工作线E：非对称有效、对称失效——机制层面的因果解释
4.0 目标
工作线D确认了EA.4是否稳健，但没有回答"为什么"。这一步要建立一个可检验的 机制解释：为什么只稀疏化吃单方有效，双边同时稀疏化反而互相抵消。

4.1 核心假说
假说H4（突发的时间相关性抵消假说）：如果吃单方和做市方都服从各自独立的 Hawkes聚集过程，两个过程虽然独立，但在统计上仍有一定概率发生"双方同时进入 突发期"的情况。当这种情况发生时，做市方在吃单方最活跃的时刻也变得最活跃， 局部流动性反而因为做市方的聚集性补充而被填平，抵消了吃单方聚集本来应该造成 的局部稀疏效果。只有当做市方保持稳定(泊松、不聚集)时，吃单方的突发才能真正 造成"来不及被补充"的局部稀疏。

这个假说如果成立，应该能观察到：对称配置下，"吃单方突发期"与"做市方补充速率 异常高的时期"存在正相关；非对称配置下这个正相关消失或减弱。

# tw/analyzer_asymmetry.py

def measure_burst_synchrony(taker_intensity_trace, maker_activity_trace, window=50):
    """
    分别对吃单方强度序列和做市方活跃度序列(比如挂单刷新频率)
    做滚动窗口内的相关系数,对比对称配置和非对称配置下这个相关系数的差异。
    """
    taker_burst = taker_intensity_trace > np.percentile(taker_intensity_trace, 80)
    maker_burst = maker_activity_trace > np.percentile(maker_activity_trace, 80)
    # 用滚动窗口计算两个二值序列的同步率,而不是简单相关系数,
    # 因为我们关心的是"同时处于突发期"这个事件层面的同步,不是连续值的线性相关
    sync_rate = rolling_cooccurrence_rate(taker_burst, maker_burst, window)
    return sync_rate

def measure_local_depth_during_taker_burst(depth_snapshots, taker_burst_mask, maker_burst_mask):
    """
    细分四种情况下的局部深度:
    (a) 吃单方突发 + 做市方也突发(对称配置下常见)
    (b) 吃单方突发 + 做市方不突发(非对称配置的核心情况,也是对称配置里偶发的情况)
    (c) 吃单方不突发 + 做市方突发
    (d) 都不突发(背景期)
    H4成立的话,应该看到(b)情况下深度显著薄于(a),
    因为(a)里做市方的补充抵消了吃单方造成的稀疏。
    """
    conditions = {
        "both_burst": taker_burst_mask & maker_burst_mask,
        "taker_only": taker_burst_mask & ~maker_burst_mask,
        "maker_only": ~taker_burst_mask & maker_burst_mask,
        "neither": ~taker_burst_mask & ~maker_burst_mask,
    }
    return {name: depth_snapshots[mask].mean() for name, mask in conditions.items()}
